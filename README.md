# Ventral_coloration_with_countershading


## Overview

This repository contains all raw data, processed data, analysis scripts, statistical model outputs, and figures used in the associated manuscript investigating abdominal coloration and luminance structure in two sympatric charr species: Dolly Varden (*Salvelinus curilus*) and White-spotted charr (*S. leucomaenis*).

## Directory Description
## 01_data

Contains all raw datasets required to reproduce the analyses.

### abdominal_images/

Raw ventral photographs used for abdominal coloration extraction.

Subdirectories:

- `2024aug20to23/` – Original image archive (August 2024).
- `2024oct9/` – Original image archive (October 2024).
- `ventral_images_DV/` – Analysis-ready images of Dolly Varden.
- `ventral_images_WSC/` – Analysis-ready images of White-spotted charr.

Only `ventral_images_DV/` and `ventral_images_WSC/` are used as inputs to
`py01_ac_area_extruction_and_heatmap.py`.
The two original image archives are retained for data provenance and reproducibility.

### processed/

Intermediate datasets generated during preprocessing.

Files include:

- `profile_line.rds`
- `df_processed.rds`

These files are produced by the preprocessing scripts and used by subsequent statistical analyses.

### RGB_lateral_16bit/

CSV files containing 16-bit RGB values measured along the lateral body surface of each individual.

Each CSV corresponds to one sampling river and is used to calculate dorsoventral luminance profiles for the Figure 2 analyses.

These files are processed using `R01_preprocessing_luminance_profile.R`.

---

### AC_area_summary_simple.csv

Summary dataset containing abdominal coloration measurements together with biological variables.

This dataset is used for all LM, LMM, GAM, and GAMM analyses and serves as the starting dataset for the statistical analyses.

---

## 02_script

Contains all R and Python scripts used in the study.

Scripts are intended to be executed approximately in numerical order following the workflow described below.

---

## 11_abdominal_data_processed

Outputs generated from abdominal image analyses.

This directory contains species-specific subdirectories (`DV/` and `WSC/`) including:

- abdominal coloration measurements (CSV)
- binary abdominal coloration masks
- abdominal coloration heatmaps
- Figure 2 upper-panel images

These files are generated by `py01_ac_area_extruction_and_heatmap.py`.

# Script Description

| Script | Purpose | Input | Output |
|---------|---------|-------|--------|
| **py01_ac_area_extruction_and_heatmap.py** | Extract abdominal coloration from ventral photographs, quantify abdominal coloration area, generate abdominal coloration masks, and produce species-specific abdominal coloration frequency heatmaps (Figure 2 upper panels). | `01_data/abdominal_images/ventral_images_DV/`<br>`01_data/abdominal_images/ventral_images_WSC/` | `11_abdominal_data_processed/DV/`<br>`11_abdominal_data_processed/WSC/` |
|---------|---------|-------|--------|
| **R00_packages.R** | Load all required R packages used throughout the analyses. | — | R environment |
| **R01_preprocessing_luminance_profile.R** | Import lateral RGB profiles, calculate luminance profiles, and prepare datasets for luminance analyses. | `01_data/RGB_lateral_16bit/` | `01_data/processed/profile_line.rds` |
| **R02_preprocessing_LMM_GAMM.R** | Import abdominal coloration measurements and biological variables and prepare the statistical analysis dataset. | `01_data/AC_area_summary_simple.csv` | `01_data/processed/df_processed.rds` |
| **R10_GAM_luminance.R** | Fit generalized additive models describing dorsoventral luminance profiles and the effects of abdominal coloration. | `profile_line.rds` | `12_lateral_data_processed/models/model_luminance.rds` |
| **R11_prediction_Figure2.R** | Generate prediction datasets from the fitted luminance GAMs. | `profile_line.rds`, `model_luminance.rds` | `pred_luminance.rds`, `red_frequency.rds`, `tile_height.rds` |
| **R12_ggplot_Figure2.R** | Generate the Figure 2 lower-panel luminance profile figure. | Figure 2 prediction datasets | `Figure2_bottom.pdf` |
| **R13_legend_Figure2.R** | Generate the standalone legend for Figure 2. | Figure 2 prediction datasets | `Figure2_bottom_legend.pdf` |
| **R20_DV_LMM_LM.R** | Fit linear mixed models and linear models for Dolly Varden abdominal coloration. | `df_processed.rds` | `DV_models.rds`, `DV_results.rds` |
| **R21_WSC_GAMM_GAM.R** | Fit generalized additive mixed models and generalized additive models for White-spotted charr abdominal coloration. | `df_processed.rds` | `WSC_models.rds`, `WSC_results.rds` |
| **R30_Fig3_predictions.R** | Generate prediction datasets for Figure 3 from the Dolly Varden models. | `df_processed.rds`, `DV_models.rds` | `Fig3_prediction.rds` |
| **R31_Fig3_plot.R** | Generate Figure 3. | `Fig3_prediction.rds` | `Fig3.pdf`, `Fig3.png` |
| **R32_Fig4_predictions.R** | Generate prediction datasets for Figure 4 from the White-spotted charr models. | `df_processed.rds`, `WSC_models.rds` | `Fig4_prediction.rds` |
| **R33_Fig4_plot.R** | Generate Figure 4. | `Fig4_prediction.rds` | `Fig4.pdf`, `Fig4.png` |
